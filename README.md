# Менеджер особистих фінансів (Personal Finance Manager)

## Призначення програми
**Personal Finance Manager** — це консольний (TUI) застосунок, розроблений на платформі .NET 10 з використанням мови C#. Його головне завдання — допомогти користувачу ефективно обліковувати свої доходи та витрати, аналізувати фінансовий стан за допомогою статистики, керувати бюджетами та відстежувати рух коштів на різних типах рахунків (дебетових та кредитних).

## Короткий опис предметної області
Управління фінансами вимагає чіткого контролю над тим, куди витрачаються гроші і звідки вони надходять. У цьому застосунку реалізовано поняття **Рахунку** (дебетова або кредитна картка), **Транзакції** (дохід або витрата), **Категорії** (з підтримкою ієрархії підкатегорій), а також **Бюджету** (ліміту витрат на певну категорію).

## Основні можливості системи
- **Робота з рахунками**: Створення дебетових та кредитних карток (з урахуванням кредитного ліміту та відсоткової ставки).
- **Фінансові операції**: Додавання та видалення доходів і витрат.
- **Категорії**: Підтримка ієрархії категорій (наприклад, `Їжа` -> `Продукти`, `Ресторани`).
- **Фільтрація та сортування**: Можливість відфільтрувати транзакції за типом, датою, категорією або відсортувати за сумою.
- **Статистика**: Формування підсумків та аналізу витрат.
- **Бюджетування**: Встановлення бюджету на певну категорію та попередження при його перевищенні.
- **Збереження даних**: Усі рахунки, операції та бюджети надійно зберігаються у файлі `data.json` за допомогою асинхронного читання та запису.

## Архітектура та структура проєкту
Проєкт логічно розділений на неймспейси:
- `PersonalFinance.Accounts` — моделі дебетових та кредитних рахунків (`AccountBase`, `CreditCard`, `DebitCard`).
- `PersonalFinance.Transactions` — моделі транзакцій та ієрархічних категорій.
- `PersonalFinance.Budgets` — бізнес-логіка розрахунку бюджетів та генерації подій при їх перевищенні.
- `PersonalFinance.Storage` — абстракція (`IDataStorage`) та реалізації (`JsonStorage`, `CsvStorage`) для асинхронного збереження даних.
- `PersonalFinance.Currencies` — робота з типами валют.
- `PersonalFinance.UI_Elements` — клас `ConsoleUI` для відмальовки інтерфейсу, що відокремлює візуал від бізнес-логіки.

## Інструкція зі збирання та запуску (без Publish)
Оскільки застосунок створено на базі .NET 10, для його запуску вам потрібен встановлений .NET 10 SDK.

1. Відкрийте термінал і перейдіть до папки проєкту (там, де лежить файл `PersonalFinance.csproj`).
2. Виконайте команду для збирання проєкту:
   ```bash
   dotnet build
   ```
3. Запустіть проєкт командою для режиму розробки:
   ```bash
   dotnet run
   ```

### Запуск релізної версії (Publish)
Для того щоб запустити зібрану версію застосунку, перейдіть в папку `publish` і запустіть файл `PersonalFinance.exe`.

## Інструкція з використання
1. При першому запуску система запропонує створити ваш перший рахунок (дебетовий або кредитний).
2. Навігація в меню здійснюється за допомогою стрілочок `Вгору` / `Вниз` на клавіатурі. Вибір підтверджується клавішею `Enter`.
3. Оберіть створений рахунок, щоб перейти до меню його управління.
4. В меню рахунку ви можете:
   - Додавати доходи/витрати (обираючи категорію зі списку).
   - Дивитися історію та видаляти помилкові транзакції.
   - Застосовувати фільтри для пошуку.
5. Для збереження даних оберіть у головному меню пункт **"Зберегти дані та вийти"**.

## Формат і спосіб збереження даних
Дані зберігаються у форматі **JSON** у файлі `data.json`, який автоматично створюється в кореневій папці під час першого збереження. Серіалізація працює асинхронно і підтримує обробку циклічних посилань (`ReferenceHandler.Preserve`), оскільки категорії мають ієрархічну залежність. У структурі JSON зберігається тип рахунку (завдяки поліморфізму та атрибуту `JsonDerivedType`), валюта та історія транзакцій.

## Тестування
У директорії з тестами знаходиться проєкт на базі NUnit.
Тести покривають:
- Позитивні сценарії: правильне нарахування коштів, правильне спрацювання бюджетів.
- Негативні сценарії: спроба витратити більше, ніж дозволяє кредитний ліміт (викидає `InsufficientFundsException`).
- Коректне зняття відсотків (`Interests()`) у випадку негативного балансу на кредитці.
- Перевірка зв'язків між батьківськими та дочірніми категоріями.

Для запуску тестів виконайте:
```bash
dotnet test
```
